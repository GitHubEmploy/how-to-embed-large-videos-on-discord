How to Embed Large Videos on Discord

Discord's default file upload limit is 25 MB (or 500 MB with Nitro). This guide covers practical ways to share larger videos without needing a subscription.

Understanding Discord's Attachment Limits

Default Limits

  • Free tier: 25 MB per file
  • Nitro Classic: 50 MB per file
  • Nitro: 500 MB per file
  • Max upload duration: No hard limit, but long videos often exceed size caps

When your video exceeds these limits, Discord will reject the upload. You have two options: compress the video or host it elsewhere and embed a link.

Compressing Videos with FFmpeg

If you want to keep full control over quality and file size, FFmpeg is your best tool. Install it from ffmpeg.org.

Basic Compression

ffmpeg -i input.mp4 -vcodec libx264 -crf 28 -acodec aac -b:a 128k output.mp4

CRF values: 18 = visually lossless, 23 = default, 28 = good compression, 35 = very compressed

Fit Under 25 MB

Target a specific file size using two-pass encoding:

# Calculate bitrate: target_size_MB * 8192 / duration_seconds - audio_bitrate
# Example: 22 MB target for a 60-second video
ffmpeg -i input.mp4 -vcodec libx264 -b:v 2.5M -acodec aac -b:a 128k output.mp4

Reduce Resolution

ffmpeg -i input.mp4 -vf "scale=854:480" -vcodec libx264 -crf 28 output_480p.mp4

Remove Audio (if not needed)

ffmpeg -i input.mp4 -c copy -an silent.mp4
💡 Tip: Always keep a copy of the original file. Compression is lossy and quality degradation is irreversible.

Embedding via Link Previews

Discord automatically generates inline video embeds for direct links to video files. Here's how to make it work:

Requirements for Embedding

  • The link must point directly to a video file (.mp4, .webm, .mov, .gif)
  • The server must allow link embeds (usually enabled by default)
  • The video should be a reasonable resolution (max 1920×1080 recommended)
  • Some hosts may block Discord's embed crawler

Testing Your Link

Paste the direct video URL into any Discord channel. If Discord shows a video player, it worked. If it shows a generic link preview, the host may not be compatible.

Using Discord's CDN

If you have Nitro, upload your video directly. Discord re-encodes it and serves it from their CDN, guaranteeing embed support.

FAQ & Troubleshooting

Why does my video show as a file instead of embedding?

The link isn't a direct video URL. You need the raw file URL (ends in .mp4), not a page URL.

Can I embed YouTube links?

Yes, Discord shows YouTube links as rich embeds with a clickable thumbnail, but the video plays in YouTube, not inline.

Does the file need to be under 25 MB to embed?

No. The size limit only applies to direct uploads. Embedded videos from external hosts can be much larger (though very large files may buffer slowly).

Are there any security concerns?

Only upload content you own the rights to. Some free hosts may have terms limiting certain content types.
